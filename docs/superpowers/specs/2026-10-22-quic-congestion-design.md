# Single-path QUIC NewReno foundation

Continue the existing C++20/Linux/OpenSSL 3.5.9 QUIC implementation in the existing isolated worktree `/home/huai/minnow-quic-proposal`. This milestone adds a byte-based NewReno controller and wires it into the current handshake/PING engine. It does not implement streams, ECN validation, persistent-congestion detection, pacing, migration, or claim complete RFC 9002 support.

Use RFC 9002 sections 2, 7.2–7.5, 7.8 and Appendix B as the behavioral reference. Fix max_datagram_size at 1200 for this engine: initial window 12000 bytes, minimum 2400. Slow start adds newly acknowledged bytes; congestion avoidance uses 1200*acked_bytes/cwnd with fractional credit retained. Application-limited ACKs do not grow the window. One congestion event halves cwnd (minimum 2400) and sets ssthresh; packets sent at or before recovery start cannot cause another cut or grow cwnd.

Physical packet flight and logical frame delivery are separate. Each protected packet's wire bytes count if ack-eliciting OR padded, including padded ACK-only Initial packets. A pure unpadded ACK does not count. Actual ACK, loss declaration or key discard removes flight bytes exactly once. A logical frame delivered through another transmission does not remove other physical packets from flight. Late/duplicate ACKs of declared-lost packets do not grow cwnd or subtract twice. Loss still finds redundant copies and padded packets. Bound physical metadata to 4096 entries per space; never evict in-flight metadata.

Enforce cwnd before allocating a packet number or consuming recovery work, with exact planned wire size. ACK-only output must remain available when fresh/retry data is congestion blocked; padded Initial ACKs remain subject to cwnd. PTO probes bypass cwnd but count bytes, retain anti-amplification and metadata bounds, and cannot be blocked behind a fresh prepared packet. Do not conflate congestion blocking with anti-amplification (congestion blocking keeps PTO armed). Expose read-only congestion stats from HandshakeConnection for callers and tests.

Decisions made by implementer: fixed 1200-byte path size, conservative window-limited detection (one max_datagram_size of headroom), independent physical flight map within PacketRecovery to preserve current logical recovery API. Existing documentation changes from the previous user request are preserved separately. Add deterministic unit and connection tests and run QUIC plus full regression, reporting existing failures.
